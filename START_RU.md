# Запуск проекта с твоим HTML

1. Открой папку google-search в VS Code. В корне должен быть package.json.
2. Используй Node.js 24. Проверка в терминале: `node --version`.
3. Скопируй `.env.example` в `.env` и укажи ключ в SERPER_API_KEY.
4. Выполни `npm start` и открой http://localhost:3000.
5. Тесты: `npm test`. Для автоматического перезапуска сервера: `npm run dev`.

Внешних npm-зависимостей нет, установка пакетов не требуется.
Не открывай HTML двойным щелчком или через Live Server: нужен сервер проекта,
который обслуживает и страницу, и /api/search.

## Что изменено

- Сохранены твоя форма, тексты, цвета, анимация рамки, мобильная компоновка.
- Язык документа исправлен на cs; CSS вынесен в public/style.css.
- Запрос браузера: GET /api/search?q=... (текст кодирует URL.searchParams).
- Запрос сервера к Serper: POST с ключом из окружения.
- Под формой появляются статус, результаты и кнопка скачивания JSON.
- JSON содержит исходный запрос, настройки поиска и массив results.
- Ошибка нового поиска очищает старые результаты и не позволяет скачать их
  как новые. Пустой успешный результат можно скачать.
- Сохранены тесты, Dockerfile и compose.yaml; тесты обновлены под GET.

## Если проект уже в GitHub Desktop

Скопируй содержимое этой папки поверх файлов в существующей папке репозитория.
Не удаляй папку .git и свой .env. В GitHub Desktop просмотри Changes,
создай коммит и нажми Push origin. Не создавай второй репозиторий для обновления.
Если репозитория ещё нет, добавь эту папку через Add local repository и создай его.
Не добавляй настоящий .env с ключом в Git или в архив для работодателя.

## Что ещё нужно проверить

Тесты подменяют ответ провайдера и не расходуют кредит. Они не доказывают,
что настоящий ключ работает. После добавления ключа проверь поиск и экспорт,
затем опубликуй приложение на хостинге с Node.js или Docker, проверь публичный
адрес и запиши собственное объяснение. Docker-конфигурация требует проверки
на машине с установленным Docker. Публикация репозитория не запускает сайт.

В этой версии все 10 тестовых блоков прошли. Проверку в настоящем браузере
здесь выполнить не удалось: проверь локально внешний вид, Enter, кнопку
поиска, ошибки и скачанный JSON. Сервер с настоящим ключом ещё не проверен.
